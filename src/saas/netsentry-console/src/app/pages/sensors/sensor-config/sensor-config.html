WireGuard creates a secure VPN tunnel from your Raspberry Pi to the cloud. The Pi initiates the connection, so it works through NAT.

Environment Variables

Add these to your Raspberry Pi's .env file: 

# === WireGuard VPN ===
WG_PRIVATE_KEY={{ wireguardConfig().privateKey }}
WG_VPS_PUBLIC_KEY=<your-vps-public-key>
VPS_ENDPOINT={{ wireguardConfig().vpsEndpoint }}
VPS_WS_URL={{ wireguardConfig().vpsEndpoint }}/ws/raspi

# === API Configuration ===
API_KEY=<generated-from-dashboard>

# === Network (eth0=WAN, eth1=LAN) ===
SURICATA_IFACE=br0
LAN_SUBNET={{ networkConfig().lanSubnet }}

Network Interfaces

Connect eth0 (WAN) to your modem and eth1 (LAN) to your router/switch.

DHCP Server

The Pi runs a DHCP server on the LAN interface to assign IPs to devices.

Network Topology

Quick Start (One-Line Installer)

Run this on your Raspberry Pi as root:

curl -fsSL https://raw.githubusercontent.com/netsentry-sensor/main/scripts/setup/install.sh | sudo bash

This installer will:

  • Install Docker, WireGuard tools, and iptables-persistent
  • Download all required files to /opt/netsentry/
  • Generate WireGuard keys and display the public key
  • Set up the network bridge (eth0 ↔ eth1)
  • Start all NetSentry services

Manual Setup (If Needed)

1. Set up network bridge

sudo /opt/netsentry/scripts/setup/setup-bridge-unified.sh

2. Configure environment

cp /opt/netsentry/.env.example /opt/netsentry/.env

3. Start services

cd /opt/netsentry && docker compose -f docker-compose.raspi.yml up -d

4. Check status

docker compose -f docker-compose.raspi.yml ps
